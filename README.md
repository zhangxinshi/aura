## 为什么它比“算命 App”更值得收藏

### 1. 先算，再解释

- 农历、干支、节气、星宿、时辰吉凶由历法算法计算
- 每个数字都可以点进去核对
- 不是“输入生日，随机吐一段话”

### 2. 数据是公开可核对的

灵镜把黄历数据做成了可检索的表格：

- 5 年逐日黄历
- 4 年 × 25 个维度的数据总表
- 2026–2029 共 209 周，每周一页
- 100 条民间说法，逐条用四年数据做对照
- 100 个黄历用词词条
- 100 个吉神凶煞词条
- 820 多篇常见问题与指南

这套“数据 + 解释”的结构，比“只给结论”的可信得多。

### 3. 答案不出浏览器

- 解梦搜索、测试计分、八字排盘、抽签全部在浏览器本地完成
- 不需要登录
- 不知道你搜过什么梦，也不知道你的生日
- 收藏只存在自己的浏览器

### 4. 首屏没有广告

打开就能用，不用等 5 秒跳过弹窗，也不诱导下载 App。  
当前全站没有广告；如果未来接入展示广告，会员不显示广告。

## English overview

**AURA (灵镜)** is a Chinese-first culture and self-exploration site combining:

- dream interpretation (325 entries)
- a daily almanac with real calendrical calculations
- 12 personality / psychology / IQ tests (255 questions, local scoring)
- BaZi four-pillar charts
- life-path numbers
- I Ching coin divination

All calculations run **locally in the browser**; no login is required, and answers are not uploaded. The almanac data is built on the MIT-licensed **lunar-javascript** astronomical calendar library, with public data tables and methodology pages.

Official site: **https://aura.mengstone.com/**
